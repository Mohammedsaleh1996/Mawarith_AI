Mawareth AI Dashboard v22 - Operations Hardening

تمت إضافة طبقات تشغيل وإدارة دون تعديل قلب محرك المواريث:

1) صفحة حالة النظام:
- Dashboard/API
- Runtime
- Database
- Telegram
- WhatsApp/WaPilot
- ngrok
- آخر رسالة وآخر خطأ

2) زر اختبار شامل:
- فحص محرك المواريث
- فحص قاعدة البيانات
- فحص وجود توكنات Telegram/WaPilot
- فحص ngrok إن كان يعمل

3) إدارة المحادثات:
- عرض المحادثات كـ Threads حسب القناة والمستخدم
- فتح المحادثة كاملة
- بحث وفلترة

4) مراجعة المسائل:
- تسجيل المسائل التي تحتاج مراجعة مثل الأسئلة الغامضة، الإيقاف الآمن، أو الأبواب المتقدمة
- تعليم المسألة: صحيح / يحتاج تعديل / خطأ / تمت المراجعة

5) النسخ الاحتياطي والاستعادة:
- تصدير إعدادات ومستخدمين وشعار
- التوكنات لا يتم تصديرها إلا باختيار صريح
- استيراد نسخة احتياطية JSON

6) أمان إضافي:
- محاولات الدخول مسجلة
- قفل مؤقت بعد محاولات فاشلة متعددة
- تغيير كلمة المرور من صفحة الأمان
- صلاحيات موسعة لكل ميزة

7) وضع مراقبة / تشغيل فعلي:
- active: يرد تلقائيًا على WhatsApp
- monitor: يستقبل ويسجل الرسائل ولا يرد

8) تشغيل مع ويندوز:
- install_windows_autostart_task.bat
- remove_windows_autostart_task.bat

run_v22_smoke_test.bat
