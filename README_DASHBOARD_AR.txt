# لوحة تحكم مفتي المواريث الذكي - Dashboard Pack v1

هذه الحزمة تضيف لوحة تحكم إنتاجية فوق نسخة مفتي المواريث الحالية، بدون تعديل قلب محرك المواريث.

## الوظائف

- Dashboard بتصميم قريب من الصورة المرجعية.
- تشغيل/إيقاف المشروع كاملًا.
- تشغيل/إيقاف Telegram منفردًا.
- تشغيل/إيقاف WhatsApp/WaPilot منفردًا.
- محادثة مباشرة مع مفتي المواريث من داخل اللوحة.
- تقارير وإحصائيات ومخطط يومي.
- سجل محادثات يومي مع تصدير CSV.
- تعديل Telegram Token و WaPilot API Token من صفحة Settings.
- استقبال WhatsApp من webhook على:

```text
/webhook/wapilot
```

- إرسال WhatsApp عبر WaPilot API باستخدام الإعداد:

```text
https://api.wapilot.net/api/v2/{instance_id}/send-message
```

## التشغيل لأول مرة

1. فك الضغط داخل مجلد المشروع.
2. شغّل:

```bat
install_dashboard_requirements.bat
```

3. شغّل:

```bat
run_dashboard.bat
```

4. افتح المتصفح على:

```text
http://127.0.0.1:8088
```

## إعداد التوكنات

افتح صفحة **الإعدادات** داخل Dashboard، ثم أدخل:

- Telegram Bot Token
- WaPilot Instance ID
- WaPilot Public Webhook URL
- WaPilot API URL Template
- WaPilot API Token

يمكنك أيضًا إنشاء ملف `.env` بجانب `dashboard_server.py` بنفس صيغة `.env.example`.

## إعداد ngrok / WaPilot Webhook

لو تستخدم ngrok الحالي:

```text
https://favorable-erased-hatbox.ngrok-free.dev/webhook/wapilot
```

ضع هذا الرابط في WaPilot كـ webhook URL.

اللوحة توفر endpoint جاهزًا:

```text
POST /webhook/wapilot
GET  /webhook/wapilot
```

```text

```

## ملاحظات أمان

- لا تضع التوكنات في ملفات تشاركها مع أحد.
- لو تم إرسال WaPilot Token في أي محادثة أو لقطة شاشة، الأفضل تغييره/إعادة توليده من مزود الخدمة قبل التشغيل الإنتاجي.
- هذه اللوحة محلية افتراضيًا على 127.0.0.1:8088. لا تجعلها عامة على الإنترنت إلا بعد إضافة مصادقة Admin.

## حدود مقصودة

- لا تستخدم RAG.
- لا تضيف ردود ثابتة لمسائل بعينها.
- لا تترك الحساب للنموذج اللغوي.
- إذا المسألة ناقصة أو خلافية، النظام يطلب توضيحًا بدل التخمين.

==============================
تشغيل تلقائي كامل v26
==============================
استخدم الملف:

run_dashboard_full_auto.bat

هذا الملف يشغل الداشبورد على البورت 8088، ويجعل السيرفر يستمع على 0.0.0.0 حتى يفتح من الموبايل داخل نفس الشبكة، ويحاول تشغيل ngrok تلقائيًا، ثم يحدث رابط WaPilot Webhook تلقائيًا إلى /webhook/wapilot.

شروط ngrok:
- ضع ngrok.exe في C:\ngrok\ngrok.exe
- أو أضفه إلى PATH
- أو اكتب مساره من صفحة الإعدادات.

لو أردت فتح الداشبورد من الموبايل داخل نفس الواي فاي، قد تحتاج تشغيل open_dashboard_firewall_admin.bat كمسؤول مرة واحدة فقط.
ngrok لا يحتاج فتح Firewall، لأنه يعمل كنفق خارجي.

## v27 WhatsApp Recovery
إذا توقف واتساب عن الاستقبال بعد تشغيل ngrok تلقائيًا، شغل:

run_wapilot_recovery_check.bat

أو افتح:
http://127.0.0.1:8088/api/wapilot/recovery-check

هذه النسخة لا تغيّر Webhook WaPilot إلى رابط ngrok عشوائي عندما يكون الدومين الثابت مفعّلًا.
