تحديث v15 Security + Ngrok Detection
====================================

ما تم تنفيذه:

1) حماية Server-side إجبارية للداشبورد والـ API
- كل صفحات الداشبورد والـ API محمية بتسجيل الدخول من السيرفر نفسه.
- لم تعد الحماية مجرد إخفاء عناصر من الواجهة.
- الاستثناءات الوحيدة:
  /login
  /api/login
  /health
  /webhook/wapilot
  /static/*
  /assets/*

سبب استثناء /webhook/wapilot:
WaPilot يحتاج الوصول إلى هذا المسار من الخارج بدون تسجيل دخول حتى يستقبل النظام رسائل واتساب.

2) إجبار تسجيل دخول جديد بعد التحديث
- تم تغيير اسم Cookie الجلسة إلى mawareth_session_v15.
- هذا يمنع المتصفح من استخدام جلسات قديمة من نسخ سابقة.
- إذا فتحت رابط ngrok بعد التحديث من نافذة خاصة/جهاز آخر، يجب أن تظهر صفحة تسجيل الدخول.

3) صلاحيات المستخدمين ما زالت تعمل
- إذا المستخدم لا يمتلك صلاحية لميزة معينة، يتم منع API المرتبط بها من السيرفر، وليس فقط إخفاء الزر.

4) اكتشاف ngrok المحسن
يدعم:
- المسار اليدوي من الإعدادات.
- ngrok الموجود في PATH.
- where ngrok.
- PowerShell Get-Command ngrok.
- Windows Store App Execution Alias.
- المسارات الشائعة مثل C:\ngrok\ngrok.exe.

5) اختبارات أمنية
بعد تشغيل الداشبورد، شغّل:
run_security_smoke_test.bat

المتوقع:
- /api/config بدون تسجيل دخول = 401
- /api/logs بدون تسجيل دخول = 401
- /webhook/wapilot يعمل بدون تسجيل دخول = 200

6) اختبار ngrok
شغّل:
check_ngrok_detection.bat

إذا ظهر ngrok version، فالأمر متاح، حتى لو كان مثبتًا من Windows Store.
