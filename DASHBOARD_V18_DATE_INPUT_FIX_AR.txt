إصلاح v18 - حقول التاريخ

المشكلة:
في واجهة RTL كان المتصفح يعرض placeholder حقول التاريخ بشكل غير مفهوم مثل: سنة/شهر/يوم بصورة مشوهة.

الإصلاح:
- جعل حقول التاريخ تعمل باتجاه LTR داخليًا مع بقاء الواجهة عربية RTL.
- ضبط CSS لعناصر date input في Chrome/Edge.
- ضبط تاريخ اليوم افتراضيًا حتى لا يظهر placeholder غير مفهوم.
- إضافة زر "كل التواريخ" لمسح فلتر التاريخ عند الحاجة.

لم يتم تعديل محرك المواريث أو منطق الحساب.
