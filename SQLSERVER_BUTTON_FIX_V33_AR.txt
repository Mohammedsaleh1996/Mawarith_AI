إصلاح v33 - أزرار SQL Server لا تستجيب

المشكلة:
بعض نسخ الواجهة كانت تتوقف فيها أزرار SQL Server عن العمل بسبب تعطل ربط JavaScript الأساسي أو cache في المتصفح.

الحل:
- إضافة ملف مستقل static/sqlserver_buttons_fix.js يعمل حتى لو app.js تعطل جزئيًا.
- ربط أزرار SQL Server عبر event delegation في مرحلة capture.
- استخدام بيانات الفورم الحالية مباشرة عند فحص الاتصال أو إنشاء القاعدة أو المزامنة أو النسخ الاحتياطي.
- إظهار النتيجة مباشرة داخل صندوق sqlResult مع تمييز نجاح/خطأ/جاري التنفيذ.

التشغيل:
1) أغلق الداشبورد الحالي.
2) شغل run_dashboard_full_auto.bat.
3) افتح Settings > SQL Server.
4) اضغط فحص الاتصال.

لو ما زال الزر لا يستجيب:
- افتح الصفحة مع Ctrl+F5 لتجاوز cache.
- أو جرّب من نافذة incognito.
