v24 إصلاحات الواجهة وتشخيص تليجرام

- تثبيت القائمة الجانبية يمين الشاشة ومنع ظهور فراغ تحتها عند التمرير.
- جعل القائمة الجانبية قابلة للتمرير داخليًا إذا زادت العناصر.
- تحسين عرض الواجهة على الموبايل.
- إصلاح التفاصيل الفنية الفارغة: إذا لم يوجد raw_json يظهر نص واضح بدل مساحة فارغة.
- حفظ تفاصيل فنية حقيقية عند فشل Telegram getMe أو polling.
- تنظيف Telegram token عند الحفظ/التحميل: إزالة مسافات، علامات اقتباس، bot prefix، واستخراج token من URL إن تم لصقه.
- إضافة فحص Telegram من الإعدادات: يعرض هل الصيغة تشبه BotFather token، وهل Telegram API قبلها.

ملاحظة مهمة: لو التوكن الحالي ظاهر بدايته غير رقمية، فهو غالبًا ليس BotFather token. التوكن الصحيح يكون مثل 1234567890:AA...
