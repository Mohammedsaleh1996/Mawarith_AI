مفتي المواريث الذكي - Runtime Final v8
=======================================

هذه الحزمة هي حل تشغيل نهائي عملي حسب التصميم المطلوب:

1) المستخدم يسأل بأي صيغة أو لهجة مدعومة.
2) النظام يطبع النص ويستخرج الورثة.
3) يحدد هل السؤال حسابي أم فقهي.
4) السؤال الحسابي يذهب إلى محرك فرائض حتمي.
5) السؤال الفقهي الأساسي يذهب إلى طبقة فقهية مضبوطة.
6) السؤال المفتوح يذهب اختياريًا إلى نموذج Ollama المحلي مع فلتر مراجعة.
7) الرد يحاول أن يكون بنفس لهجة السائل قدر الإمكان.

المبادئ:
--------
- لا RAG.
- لا ردود ثابتة لمسائل بعينها.
- لا ترك للحساب للنموذج اللغوي.
- لا تخمين عند الغموض.
- المسائل الخلافية أو الناقصة تُحال إلى سؤال توضيحي.

التشغيل:
--------
1) فك الضغط داخل مجلد المشروع.
2) شغل:
   run_cli.bat

API:
----
شغل:
   run_api.bat

ثم أرسل POST إلى:
   http://127.0.0.1:8000/ask

مثال JSON:
{
  "question": "واحد مات وساب مراته وأمه وابنه وبنته، القسمة تبقى إزاي؟"
}
