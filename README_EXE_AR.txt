تشغيل الداشبورد كملف EXE
=========================

الملف الرئيسي:
Start_Mawareth_AI_Dashboard.exe

طريقة التشغيل:
1) فك الضغط عن الحزمة كاملة في مجلد واحد.
2) اضغط مرتين على Start_Mawareth_AI_Dashboard.exe.
3) أول تشغيل قد يثبت المتطلبات تلقائيًا.
4) ستفتح نافذة تشغيل سوداء؛ اتركها مفتوحة أثناء استخدام الداشبورد.
5) سيفتح المتصفح تلقائيًا على: http://127.0.0.1:8088

مهم:
- لا تنقل ملف EXE وحده خارج مجلد المشروع؛ يجب أن يبقى بجوار dashboard_server.py.
- هذا EXE هو Launcher لتشغيل المشروع، وليس تحويلًا كاملًا لكل Python إلى ملف واحد.
- لازم Python يكون مثبتًا على ويندوز ومضافًا إلى PATH.
- لو ظهر تحذير Windows SmartScreen فهذا طبيعي لأن الملف غير موقّع رقميًا.
- لإيقاف المشروع: أغلق نافذة التشغيل أو اضغط CTRL+C داخلها.

الملفات الأساسية لم تتغير:
- محرك المواريث لم يتم تعديله.
- التوكنات تظل محفوظة في Windows Registry كما في النسخة السابقة.
